# Puentes Jóvenes Conectados

Quiero que diseñes una página web responsive, juvenil, cálida, accesible y visualmente atractiva para un proyecto llamado “PUENTES – Red Juvenil Intercultural”.

IMPORTANTE:

No quiero que parezca una landing page corporativa, una página genérica creada por inteligencia artificial ni una plataforma médica. Debe sentirse humana, cercana, juvenil y amigable para adolescentes y jóvenes.

OBJETIVO DEL PROYECTO

PUENTES es una red juvenil híbrida que combina recursos digitales con educación presencial entre pares.

Busca acercar a adolescentes y jóvenes:

- información clara y confiable;

- conocimiento sobre sus derechos;

- orientación hacia servicios y recursos existentes;

- contenidos sobre salud sexual y reproductiva;

- prevención del embarazo adolescente e infantil;

- consentimiento y relaciones saludables;

- prevención de violencias;

- proyecto de vida;

- oportunidades para participar como agentes juveniles de cambio.

La plataforma digital puede ser utilizada por adolescentes y jóvenes de diferentes territorios del Perú.

El componente presencial de PUENTES se implementaría progresivamente mediante Agentes PUENTES: jóvenes capacitados para compartir información entre pares, desarrollar actividades educativas y conectar a otros adolescentes con recursos y servicios existentes. Los agentes NO reemplazan a psicólogos, profesionales de salud ni autoridades.

IDENTIDAD VISUAL

La mascota principal se llama KAMU y es un mono joven, amigable y expresivo.

Kamu debe funcionar como acompañante visual de la experiencia. Puede aparecer en distintas secciones mediante ilustraciones, pequeños mensajes, preguntas o recomendaciones.

La identidad visual debe utilizar principalmente:

- morado como color principal;

- turquesa como color secundario;

- naranja como color de acento;

- crema/blanco y tonos pastel como fondos.

Utiliza:

- formas orgánicas;

- esquinas redondeadas;

- pequeñas ilustraciones;

- hojas o elementos naturales sutiles;

- iconos sencillos;

- tarjetas;

- bastante espacio en blanco.

Evita:

- estética futurista;

- degradados excesivos;

- apariencia corporativa;

- exceso de texto;

- elementos 3D genéricos;

- fotografías de stock;

- diseño infantil;

- exceso de emojis;

- estética típica de una página generada por IA.

Debe ser juvenil, pero NO infantil.

ARQUITECTURA DE LA PÁGINA PRINCIPAL

Construye una página vertical con scroll fluido.

1. HEADER / NAVEGACIÓN

Logo:

PUENTES

Red Juvenil Intercultural

Menú:

Infórmate

Mis derechos

Orientación

Proyecto de vida

Agentes PUENTES

Sobre la red

Añade un botón destacado:

“Necesito orientación”

La navegación debe permitir desplazarse a las diferentes secciones.

2. HERO PRINCIPAL

Título principal:

“Todo lo que sientes importa.

Tu futuro también.”

Subtítulo:

“Información clara, derechos, orientación y una red de jóvenes dispuestos a construir puentes contigo.”

Botones:

“Quiero comenzar”

“Necesito orientación”

Coloca a Kamu como elemento visual principal de esta sección.

El diseño debe transmitir tranquilidad, confianza y cercanía.

3. SECCIÓN “¿QUÉ NECESITAS HOY?”

Título:

“¿Qué necesitas hoy?”

Subtítulo:

“No tienes que saber exactamente qué buscar. Empieza por donde necesites.”

Crear seis tarjetas interactivas:

1. INFÓRMATE

“Encuentra información clara para tomar decisiones.”

2. MIS DERECHOS

“Conoce tus derechos y aprende a reconocer cuándo no están siendo respetados.”

3. NECESITO ORIENTACIÓN

“Encuentra opciones de apoyo y rutas para saber a dónde acudir.”

4. PROYECTO DE VIDA

“Explora tus metas, decisiones y posibilidades para el futuro.”

5. SER AGENTE PUENTES

“Descubre cómo puedes acompañar y generar cambios junto a otros jóvenes.”

6. SOBRE PUENTES

“Conoce nuestra red y cómo conectamos lo digital con las comunidades.”

Cada tarjeta debe ser clicable.

4. SECCIÓN DE KAMU

Crear una sección visual y cálida donde aparezca Kamu.

Texto:

“¡Hola! Soy Kamu.”

“No estoy aquí para decirte qué hacer. Estoy aquí para ayudarte a encontrar información, conocer tus opciones y saber dónde buscar apoyo cuando lo necesites.”

Añadir tres conceptos pequeños:

Información confiable

Sin juzgarte

A tu ritmo

5. SECCIÓN “¿QUÉ ES PUENTES?”

Explicar visualmente el concepto mediante cuatro palabras conectadas:

INFÓRMATE → DECIDE → CONECTA → CAMBIA

Texto breve:

“PUENTES conecta información confiable, participación juvenil y recursos de apoyo para que más adolescentes puedan tomar decisiones informadas y encontrar acompañamiento cuando lo necesiten.”

No utilizar párrafos largos.

6. SECCIÓN “UNA RED, DOS FORMAS DE LLEGAR”

Crear dos bloques visuales conectados por un puente.

PUENTES DIGITAL

- Web interactiva

- Historietas

- Videos y contenido juvenil

- Recursos descargables

- Redes sociales

PUENTES EN COMUNIDAD

- Agentes juveniles

- Educación entre pares

- Actividades participativas

- Materiales offline

- Conexión con organizaciones y servicios existentes

Mostrar visualmente que ambos componentes forman parte de una misma red y se retroalimentan.

7. SECCIÓN “YO TAMBIÉN SOY PUENTE”

Esta sección presenta a los Agentes PUENTES.

Título:

“¿Quieres ser parte del cambio?”

Texto:

“Los Agentes PUENTES son jóvenes que se preparan para informar, escuchar sin juzgar, desarrollar actividades entre pares y conectar a otros jóvenes con recursos y servicios de su comunidad.”

Mostrar visualmente esta ruta:

APRENDO → PRACTICO → ACOMPAÑO → CONECTO → MULTIPLICO

Botón:

“Quiero conocer a los Agentes PUENTES”

Frase destacada:

“Yo también soy PUENTE.”

8. RECURSOS PUENTES

Crear tarjetas para:

- Kit del Agente PUENTES

- Historietas

- Kamu responde

- Recursos descargables

- Redes sociales

Estas tarjetas deben quedar preparadas para enlazar posteriormente a otros recursos.

9. CIERRE / FOOTER

Logo PUENTES

Kamu pequeño

Frase:

“Infórmate. Decide. Conecta. Cambia.”

Añadir espacios para:

Fuentes

Créditos

Contacto

Redes sociales

REQUISITOS DE EXPERIENCIA DE USUARIO

- Mobile-first y totalmente responsive.

- Navegación extremadamente sencilla.

- Botones grandes y fáciles de identificar.

- Alto contraste y buena legibilidad.

- No saturar las pantallas.

- Utilizar lenguaje sencillo.

- Las secciones deben sentirse conectadas al hacer scroll, no como diapositivas separadas.

- Crear transiciones visuales suaves mediante cambios sutiles de fondo y formas orgánicas.

- Mantener consistencia de colores, tipografía, botones, tarjetas e iconografía.

- Priorizar accesibilidad.

- Evitar animaciones excesivas.

- La web debe poder ampliarse posteriormente con nuevas páginas y recursos.

IMPORTANTE SOBRE CONTENIDO SENSIBLE

La plataforma aborda temas de salud sexual, violencia y derechos de adolescentes. No presentar a PUENTES como un servicio médico, psicológico, jurídico o de emergencia.

Cuando corresponda, la plataforma debe dirigir a servicios oficiales y profesionales, no intentar sustituirlos.

OBJETIVO DE ESTA PRIMERA VERSIÓN

Por ahora, crea principalmente:

1. sistema visual;

2. página de inicio completa;

3. navegación;

4. estructura preparada para futuras subpáginas.

No inventes estadísticas, organizaciones aliadas, números de emergencia, testimonios, datos médicos ni información institucional.

Utiliza placeholders claramente identificados cuando falte información que posteriormente será validada.
